# Portfolio — Saksham Mittal

Personal portfolio site, deployed at [sakshammittal.vercel.app](https://sakshammittal.vercel.app).

Static site (HTML/CSS/JS) with a dark/light theme toggle, reduced-motion support,
and responsive layouts. `index.html` is the main page; `projects.dc.html` and
`coursework.dc.html` are secondary pages rendered via `support.js`.

## Local preview

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy

Pushed to Vercel from this repo (static, no build step).
