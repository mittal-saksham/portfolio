About Me

Building Products That Ship

Hi, I'm Saksham, a software engineer and final-year B.Tech. (Information Technology) student at NSUT Delhi, currently a Software Development Engineer intern at Writesonic (YC S21) in San Francisco. I like turning Figma mocks and design docs into systems that actually run in production.

At Writesonic I build backend services and REST APIs for a GEO/SEO analytics suite, owned the GEO Ads feature end-to-end across backend and a React/Next.js front-end, and shipped a password-policy security feature with Datadog observability through release.

Before that, at Ericsson I built an end-to-end CI/CD pipeline with GitLab and Docker. Outside of shipping I research IoT security — my two-stage MQTT authentication framework is publishing at ICT4SD 2026 (Springer).
